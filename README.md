PROJECT OVERVIEW:
Employee Attrition Prediction
Business Intelligence + Predictive Analytics
Production-oriented modular design

Dataset Description:
The Employee Attrition dataset contains demographic, compensation, job, satisfaction, performance, 
workload and tenure variables. The target variable is Attrition.

Feature Engineering:
Created business-relevant features such as Income_Group, Experience_Group, Working_Hours_Group, 
Salary_Level, Long_Term, Senior_Employee and High_Performer. Categorical variables are encoded and scaling is applied where appropriate.

Exploratory Data Analysis:
Eight recommended visualizations: Attrition Distribution, Gender vs Attrition, Department vs Attrition,
Job Satisfaction vs Attrition, Monthly Income Distribution, Age vs Attrition, Overtime vs Attrition, and Correlation Heatmap.

Business Intelligence & Dashboard:
Dashboard KPIs can include employee count, attrition rate, department attrition, overtime-related attrition,
satisfaction patterns, income distribution, feature importance and an employee prediction form.

Testing Report:
Test data loading, preprocessing, target encoding, prediction with valid inputs, 
rejection of invalid inputs, model loading, authentication and dashboard behavior. Record Pass/Fail results and expected behavior.

Conclusion:
The project demonstrates an end-to-end BI and predictive analytics workflow integrating preprocessing,
machine learning, business reporting, testing, security, scalability and deployment planning.
